## ✨ Возможности

| Модуль | Описание |
|--------|----------|
| 📋 **Просмотр данных** | Таблица, типы данных, статистика, пропуски |
| 📈 **Визуализация** | Интерактивные графики: гистограммы, boxplot'ы, scatter plot, круговые, матрица корреляций |
| 🤖 **Математические модели** | Линейная регрессия, логистическая регрессия, дерево решений, случайный лес, градиентный бустинг, K-Means кластеризация |
| 📊 **Бизнес-метрики** | Retention N+1, Cohort анализ, RFM, воронка конверсии, LTV, Churn Rate |
| 📚 **Справочник pandas** | 80+ функций с примерами и умным поиском |

## 🚀 Быстрый старт

### Установка

```bash
# Клонируем репозиторий
git clone https://github.com/ваш-аккаунт/StatSnap.git
cd StatSnap

# Создаём окружение
python -m venv .venv

# Активируем
# Windows:
.venv\Scripts\activate
# UNIX:
source .venv/bin/activate

# Устанавливаем зависимости
pip install -r requirements.txt
